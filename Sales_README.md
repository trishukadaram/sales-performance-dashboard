## 📌 Overview

This project analyzes **9,994 sales records** from a retail superstore to uncover trends, regional performance, product insights, and profit margins. The analysis answers key business questions using Python and delivers actionable insights through 5 visualizations.

> Built as part of a Data Analyst portfolio project showcasing skills in EDA, data cleaning, and business intelligence.

## 🚀 Getting Started

### Prerequisites
- Python 3.8+
- Jupyter Notebook

### Installation

```bash
# Clone the repository
git clone https://github.com/trishukadaram/sales-performance-dashboard.git

# Navigate into the project
cd sales-performance-dashboard

# Install required libraries
pip install pandas matplotlib seaborn openpyxl jupyter

# Launch Jupyter Notebook
jupyter notebook
```

### Open the notebook
- Click on `sales_dashboard.ipynb`
- Run each cell with `Shift + Enter`
