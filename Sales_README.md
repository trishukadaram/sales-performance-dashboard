## 👋 About This Project

I built this project to practice my Python and data analysis skills on a real-world dataset. As a Business Data Analyst, I work with sales and financial data every day — so this felt like a natural fit. I wanted to go beyond just running queries and actually visualize the story behind the numbers.

The dataset has **9,994 sales records** from a retail superstore. I cleaned it, explored it, and pulled out insights that I would actually present to a business team.

---

## 📈 Key Business Insights

Here's what I found after analyzing the data:

| Metric | Value |
|---|---|
| 💰 Total Sales | $2,297,200.86 |
| 📈 Total Profit | $286,397.02 |
| 📊 Overall Profit Margin | 12.5% |
| 🥇 Best Performing Region | West |
| 🥉 Worst Performing Region | South |
| ✅ Most Profitable Category | Technology |
| ⚠️ Least Profitable Category | Furniture |
| 🗓️ Best Sales Month | November 2017 |

A few things that stood out to me:
- **Furniture has the lowest profit margin** — high discounts are likely eating into profits
- **The West region outperforms all others** — worth investigating what they're doing right
- **November is consistently the best month** — driven by holiday season and Black Friday

## 🚀 Getting Started

### Prerequisites
- Python 3.8+
- Jupyter Notebook

### Installation

```bash
# Clone the repository
git clone https://github.com/trishukadaram/sales-performance-dashboard.git

# Navigate into the project
cd sales-performance-dashboard

# Install required libraries
pip install pandas matplotlib seaborn openpyxl jupyter

# Launch Jupyter Notebook
jupyter notebook
```

### Open the notebook
- Click on `sales_dashboard.ipynb`
- Run each cell with `Shift + Enter`
